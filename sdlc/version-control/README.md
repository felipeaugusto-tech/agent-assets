# Version Control Phase Standards

**Rule-ID prefix:** `VCS`

## Purpose

Version control standards define how code is branched, committed, reviewed, and merged. Consistent practices here reduce merge conflicts, improve code review quality, and make the history of the codebase a reliable audit trail.
