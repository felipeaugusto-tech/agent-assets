# On-Demand Playbooks

Manually triggered playbooks for specific situations — bug triage, feature design, code review, etc. Run these when a particular need arises.

## Playbooks

| Playbook | Target Roles | Description |
|----------|-------------|-------------|
| [Generate C4 Architecture Diagrams](generate-architecture-diagrams.md) | Architect, Tech Lead | Generate C4 model diagrams from codebase analysis |
| [Create Context Pack](create-context-pack.md) | Architect, Tech Lead, Backend Dev, Frontend Dev, Fullstack Dev | Create AI context files for IDE integration |
| [Enhance Acceptance Criteria](enhance-requirements.md) | Product Owner, Business Analyst, QA Engineer | Transform vague requirements into detailed, testable acceptance criteria |
| [Generate Unit Tests](generate-unit-tests.md) | Backend Dev, Frontend Dev, Fullstack Dev, QA Automation | Generate comprehensive unit tests for existing code |
| [Generate Integration Tests](generate-integration-tests.md) | Backend Dev, Fullstack Dev, QA Automation, QA Engineer | Generate test suites for third-party integrations |
| [Validate Acceptance Criteria](validate-acceptance-criteria.md) | QA Engineer, QA Automation, Frontend Dev | Validate ACs against live application using Playwright MCP |
| [Run Playwright Assisted Testing](run-assisted-testing.md) | QA Engineer, QA Automation, Frontend Dev | Discover UI elements and generate E2E test suites |
| [Identify Test Gaps](identify-test-gaps.md) | QA Engineer, QA Automation, Tech Lead | Analyze test coverage gaps and create remediation plan |
| [Run Delta Analysis](run-delta-analysis.md) | Architect, Tech Lead, Engineering Manager | Analyze change impact on code, docs, and risk |
| [Analyze Database Schema](analyze-database-schema.md) | DBA, Backend Dev, Architect | Schema analysis, relationships, migration health |
| [Audit CI/CD Pipeline](audit-ci-cd-pipeline.md) | DevOps Engineer, SRE, Tech Lead | Pipeline structure, deployment patterns, improvements |
| [Audit Observability and Reliability](audit-observability.md) | SRE, DevOps Engineer, Tech Lead | Logging, metrics, alerting, SLOs, incident readiness |
| [Generate Support Documentation](generate-support-documentation.md) | Support Engineer, Technical Writer | Troubleshooting guides, FAQ, known issues |
| [Audit UI Patterns and Accessibility](audit-ui-patterns.md) | UX Designer, Frontend Dev | Component inventory, accessibility audit, UI consistency |

## When to Use This Category

- A specific task or situation requires structured guidance
- Ad-hoc analysis, design, or review work
- Any non-recurring, non-onboarding activity
