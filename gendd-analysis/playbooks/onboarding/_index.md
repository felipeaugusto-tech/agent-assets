# Onboarding Playbooks

Run-once playbooks for repository setup, brownfield analysis, and initial team onboarding. These are typically token-heavy and executed when first adopting GenDD-Flow or joining a project.

## Playbooks

| Playbook | Target Roles | Description |
|----------|-------------|-------------|
| [Run Brownfield Analysis](run-brownfield-analysis.md) | Architect, Tech Lead, Backend Dev, Frontend Dev, Fullstack Dev, Engineering Manager | First-time codebase analysis and documentation |
| [Create Context Pack](../../workflows/create-context-pack.md) | Architect, Tech Lead, Backend Dev, Frontend Dev, Fullstack Dev | Set up AI context files for IDE integration |

## When to Use This Category

- First time adopting GenDD-Flow on a repository
- New team member joining an existing project
- Initial codebase analysis and documentation setup
