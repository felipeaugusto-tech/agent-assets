# Recurring Playbooks

## Playbooks

| Playbook | Target Roles | Description |
|----------|-------------|-------------|
| [Update Documentation Incrementally](update-documentation.md) | Technical Writer, Tech Lead, Architect | Update only affected documentation after code changes |
| [Review Test Coverage](review-test-coverage.md) | QA Engineer, QA Automation, Tech Lead, Engineering Manager | Periodic test coverage assessment and remediation planning |
| [Refresh Context Pack](refresh-context-pack.md) | Tech Lead, Architect | Update AI context files after significant changes |

## When to Use This Category

- Sprint or iteration boundaries
- Scheduled audits (security, quality, dependencies)
- Periodic documentation or metric updates
