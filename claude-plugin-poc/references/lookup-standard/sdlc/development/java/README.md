# Development Phase — Java Overlay

**Tech:** Java
**Rule-ID prefix:** `DEV-JAVA`
**Applies to:** `**/*.java`
**Extends:** [`sdlc/development/`](../README.md)

## Purpose

This overlay extends the agnostic development-phase standards with rules specific to Java. It covers Java naming conventions, code structure, and exception handling patterns that are idiomatic to the language.

## Files in this overlay

| File | Rule IDs | Summary |
|---|---|---|
| [`coding-standards.md`](coding-standards.md) | DEV-JAVA-001 | Java naming conventions, structure, and style rules |
| [`error-handling.md`](error-handling.md) | DEV-JAVA-002 | Java exception hierarchy and handling rules |

## How to use

Read the agnostic standards first (`sdlc/development/coding-standards.md`, `sdlc/development/error-handling.md`), then read the corresponding files here. All agnostic rules remain in full effect; this overlay adds Java-specific rules.
