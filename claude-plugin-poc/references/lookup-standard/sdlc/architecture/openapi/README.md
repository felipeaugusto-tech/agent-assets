# Architecture Phase — OpenAPI Overlay

**Tech:** OpenAPI
**Rule-ID prefix:** `ARC-OPENAPI`
**Applies to:** `openapi.yaml`, `openapi.json`, `*.oas.yaml`, `*.oas.json`
**Extends:** [`sdlc/architecture/`](../README.md)

## Purpose

This overlay extends the agnostic architecture-phase standards with rules specific to teams designing APIs using the OpenAPI Specification. These rules govern contract-first workflow, specification quality, and tooling expectations.

## Files in this overlay

| File | Rule IDs | Summary |
|---|---|---|
| [`api-design.md`](api-design.md) | ARC-OPENAPI-001 | OpenAPI-specific contract-first and specification quality rules |

## How to use

Read `sdlc/architecture/api-design.md` first (agnostic rules), then read this overlay for OpenAPI-specific rules. All agnostic rules remain in full effect.
